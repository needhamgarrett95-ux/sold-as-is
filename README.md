# Sold As-Is

An online marketplace moped flipper/collector game. Scroll the listings, spot the deals, flip your way to the ultimate 28-bike collection.

**Soul of the game:** collecting. Flipping and restoration fund the hunt.

## Project layout

- `src/` — game source (HTML/CSS/JS, Canvas)
- `docs/` — design docs, game outline, research
- `assets/bikes/` — bike sprites (new art, clean slate)
- `assets/ui/` — UI art
- `assets/audio/` — music and SFX

## Deploy

Deploys to Firebase Hosting via GitHub Actions on push to `main`.
