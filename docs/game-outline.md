# Sold As-Is — Game Design Outline

## The fantasy
You're the sharpest flipper on the marketplace. Everyone else scrolls past the deals. You don't.

## Core loop
1. **Scroll the Feed** — marketplace listings, new drops in real time, good ones go fast
2. **Spot the deal** — photos hide secrets, inspection skill reveals more, haggle or Buy Now
3. **Garage triage** — restore it, strip it for parts, flip it quick, or keep it
4. **Restore** — parts store with fluctuating prices, budget discipline matters
5. **Re-list** — your own photos/descriptions/pricing, rep affects sales
6. **Collect** — keeper wall, sets by brand/decade/style, full 28-bike collection is endgame

## Money (no racing, all brains)
- **Information edge** — sellers don't always know what they have
- **Market trends** — buy the style before it trends, sell into the hype
- **Haggling** — make offers, read the room
- **Strip vs. restore** — part-out math, real flipper decisions
- **Seller reputation** — good flips build rating, unlocks rare listings
- **Commissions** — source and build to spec for paying clients

## Progression
Start with $1,500 → wider search radius → rare listings → more garage slots → storefront.
Endgame: full 28-bike collection, fully restored, on the wall.
